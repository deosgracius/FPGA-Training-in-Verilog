Gate 1 — AND
Output is 1 only when ALL inputs are 1. Think of it as multiplication.
A=0, B=0 → Y=0
A=0, B=1 → Y=0
A=1, B=0 → Y=0
A=1, B=1 → Y=1
In Verilog:
verilogmodule and_gate(
    input  a,
    input  b,
    output y
);
    assign y = a & b;
endmodule

Gate 2 — OR
Output is 1 when ANY input is 1.
A=0, B=0 → Y=0
A=0, B=1 → Y=1
A=1, B=0 → Y=1
A=1, B=1 → Y=1
verilogmodule or_gate(
    input  a,
    input  b,
    output y
);
    assign y = a | b;
endmodule

Gate 3 — NOT
Flips the input. Also called an inverter.
A=0 → Y=1
A=1 → Y=0
verilogmodule not_gate(
    input  a,
    output y
);
    assign y = ~a;
endmodule

Gate 4 — XOR (Exclusive OR)
Output is 1 when inputs are DIFFERENT. This one is critical — you will use it to build an adder later.
A=0, B=0 → Y=0  (same → 0)
A=0, B=1 → Y=1  (different → 1)
A=1, B=0 → Y=1  (different → 1)
A=1, B=1 → Y=0  (same → 0)
verilogmodule xor_gate(
    input  a,
    input  b,
    output y
);
    assign y = a ^ b;
endmodule

Gate 5 — NAND
AND followed by NOT. This is the most important gate in existence — every other gate can be built from NAND gates alone. This is why it's used in almost all modern memory (NAND Flash).
A=0, B=0 → Y=1
A=0, B=1 → Y=1
A=1, B=0 → Y=1
A=1, B=1 → Y=0
verilogmodule nand_gate(
    input  a,
    input  b,
    output y
);
    assign y = ~(a & b);
endmodule

Verilog Structure — What Every File Looks Like
Every Verilog file describes a module. A module is a box with inputs coming in and outputs going out. Inside the box you describe the logic.
verilogmodule module_name(
    input  wire signal_in,    // something coming in
    output wire signal_out    // something going out
);

    // describe the circuit here

endmodule
Three rules to remember right now:
Rule 1: Every module starts with module and ends with endmodule.
Rule 2: assign is for combinational logic — logic that has no memory, output depends only on current inputs.
Rule 3: Inputs and outputs are the only way the outside world communicates with your module. Think of them as pins on a chip.

Operators Cheat Sheet
veriloga & b    // AND
a | b    // OR
a ^ b    // XOR
~a       // NOT
a ~^ b   // XNOR (opposite of XOR)
a && b   // logical AND (for conditions)
a || b   // logical OR (for conditions)

Multi-bit Signals — Buses
So far everything has been 1 bit. Real hardware uses buses — groups of wires treated as a number.
veriloginput  [7:0] data_in    // 8-bit input (bits 7 down to 0)
output [3:0] data_out   // 4-bit output
input  [31:0] word      // 32-bit input (used in your CPU later)
Accessing individual bits:
verilogwire [7:0] byte = 8'b10110100;

wire msb = byte[7];      // most significant bit = 1
wire lsb = byte[0];      // least significant bit = 0
wire nibble = byte[3:0]; // lower 4 bits = 0100
Number formats in Verilog:
verilog8'b10110100    // 8-bit binary
8'hB4          // 8-bit hexadecimal (same value)
8'd180         // 8-bit decimal (same value)
  ^^ size in bits
    ^ format: b=binary, h=hex, d=decimal

Your First Real Circuit — The Half Adder
Now we use what you just learned to build something real.
A half adder adds two 1-bit numbers together. When you add two bits you get two outputs — the sum and the carry (overflow).
0 + 0 = 00  (sum=0, carry=0)
0 + 1 = 01  (sum=1, carry=0)
1 + 0 = 01  (sum=1, carry=0)
1 + 1 = 10  (sum=0, carry=1)  ← 1+1=2, which is 10 in binary
Look at the pattern:

Sum is 1 when inputs are DIFFERENT → that is XOR
Carry is 1 only when BOTH inputs are 1 → that is AND

verilogmodule half_adder(
    input  a,
    input  b,
    output sum,
    output carry
);
    assign sum   = a ^ b;   // XOR
    assign carry = a & b;   // AND
endmodule
This is real. Two gates. Two lines. A working adder.

Your First Testbench
A testbench is Verilog that tests your Verilog. It has no inputs or outputs — it just applies signals and lets you observe the result.
verilogmodule half_adder_tb;

    // Declare signals
    reg a, b;           // reg = signal we drive
    wire sum, carry;    // wire = signal we observe

    // Connect the module we are testing
    half_adder uut(
        .a(a),
        .b(b),
        .sum(sum),
        .carry(carry)
    );

    initial begin
        // Test all 4 input combinations
        a=0; b=0; #10;  // wait 10 time units
        $display("a=%b b=%b | sum=%b carry=%b", a, b, sum, carry);

        a=0; b=1; #10;
        $display("a=%b b=%b | sum=%b carry=%b", a, b, sum, carry);

        a=1; b=0; #10;
        $display("a=%b b=%b | sum=%b carry=%b", a, b, sum, carry);

        a=1; b=1; #10;
        $display("a=%b b=%b | sum=%b carry=%b", a, b, sum, carry);

        $finish;
    end

endmodule
